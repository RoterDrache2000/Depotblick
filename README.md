# Depotblick

Dein Depot, deine Statistiken, deine Sparpläne und dein Budget. Läuft komplett im Browser, ohne Konto und ohne Server: Deine Daten bleiben auf deinem Gerät.

- **Öffnen:** die Adresse dieser Seite (GitHub Pages), z. B. `https://roterdrache2000.github.io/depotblick/`
- **Als App installieren:** PC mit Chrome oder Edge: Installieren-Symbol in der Adressleiste. Android: Menü > „App installieren“. iPhone: Safari > Teilen > „Zum Home-Bildschirm“.
- **Daten sichern:** In der App unter Einstellungen eine Speicherdatei anlegen (Chrome/Edge am PC) oder ein Backup exportieren.

In diesem Repository liegt nur die App selbst, keine Depotdaten.
